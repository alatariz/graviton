GRAVITON V3.0.0 Documentation

Autonomous AI Acceleration & Intelligent Context Engine for Google Antigravity

Graviton is an ultra-fast, zero-auth terminal accelerator and Autonomous Intelligent Context Engine built exclusively for the Google Antigravity CLI (agy). It executes 100% offline on your local machine with zero external API keys and zero third-party dependencies, orchestrates 20 Autonomous Background Engines, prunes terminal and stack trace noise (-95% tokens), intercepts minified file context bombs, pins target files directly into AI prompts, executes turn-by-turn delta diff compression with out-of-band disk sync, transpiles Office & PDF docs in 0ms via content-addressable cache, and provides Antigravity IDE conversation history management with sub-millisecond dispatch.

⚡ Technical Fact: Zero External LLM Calls & Zero Runtime Dependencies.
Graviton does not route your prompts through an intermediate third-party AI model, and requires zero external npm packages. All keyword matching, AST traversal, terminal pruning, document transpilation, and delta diffing execute 100% locally on your CPU using Node.js V8 standard libraries. Exactly ONE API call occurs—directly to Google Antigravity.

3. Prerequisites & Installation

Follow these straightforward steps to set up Graviton on Windows, macOS, or Linux.

Step 1: Install Node.js (Version >= 18.0.0)

Graviton runs natively on modern Node.js using ES Modules:

# Windows (PowerShell): winget install OpenJS.NodeJS.LTS # macOS (Homebrew): brew install node # Linux (Debian/Ubuntu): curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt-get install -y nodejs # Verify version: node -v # Should output v18.0.0 or newer

Step 2: Install Google Antigravity CLI (agy)

Graviton connects to the official Google Antigravity command-line tool (agy):

# Windows PowerShell: irm https://antigravity.google/cli/install.ps1 | iex # macOS & Linux: curl -fsSL https://antigravity.google/cli/install.sh | bash # Verify CLI: agy --version

Step 3: Install Graviton Globally

Install Graviton globally directly from the GitHub repository:

npm install -g github:alatariz/graviton

Step 4: Verify System Health (Graviton Doctor)

Run Graviton's self-diagnostic doctor to verify your environment:

# System diagnostic check: grav doc # Or with automated repair (auto-installs agy if missing): grav doc --fix

4. Smart Target Pinning (Intelligent Context Scoper)

Without Graviton, when a developer prompts "Fix email validation in auth.js", the AI model executes 3 to 4 exploratory search loops across 200 files (costing 5,000–12,000 tokens and 30+ seconds).

Graviton inspects your workspace AST locally in < 0.4ms, isolates the matching file, formats an absolute file:/// clickable reference, and pins it directly into the initial AI turn:

# Execute quote-free prompt: grav Fix email validation and return 422 in src/auth.js # Output: # [GRAVITON] Pinned target file: file:///C:/project/src/auth.js # Antigravity immediately begins code edits on src/auth.js on Turn 1!

8. Automated Syntax Sanity Guard

Immediately upon AI task completion, Graviton inspects all modified files locally:

  • JavaScript / Node: .js, .mjs, .cjs validated via node --check
  • JSON: Validated via strict JSON schema parser
  • Python: Validated via python -m py_compile

If broken syntax is introduced, Graviton instantly alerts you before tests run:

[🚨 GRAVITON SANITY ALERT] 1 broken syntax file(s) detected! ✖ src/routes/user.js: Unexpected token '}' (line 42) 💡 Recommendation: Run 'grav rb' to revert changes.

9. Safety Rollback Guard & Diff Viewer (grav rb & grav diff)

Every file modified by the AI is mirrored in ~/.graviton/backups/ before Antigravity runs:

# Review colorized code changes: grav diff # Revert modified files and remove newly generated AI files: grav rb # (or grav undo)

15. Privacy, Security & Trust Guarantees

🔒 100% Offline by Design
Zero outbound tracking, analytics, or telemetry beacons. Prompts and filenames never touch any external server.
🛡️ Zero Runtime Dependencies
The CLI engine requires 0 third-party npm runtime dependencies, eliminating supply-chain attack risks.
🧹 Automated Secret Scrubbing

16. Troubleshooting & FAQ

Q: "Google Antigravity CLI (agy) was not found on this machine"

Solution: The Antigravity Desktop App is a GUI application. Run grav doc --fix, or install the official CLI directly:

# Windows PowerShell: irm https://antigravity.google/cli/install.ps1 | iex # macOS & Linux: curl -fsSL https://antigravity.google/cli/install.sh | bash

Q: "Command 'grav' not recognized after installation"

Solution: Ensure your global npm bin directory is registered in your system PATH environment variable:

npm config get prefix # Add the returned path (e.g. C:\Users\<Name>\AppData\Roaming\npm) to your PATH.
